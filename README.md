# 星塔机器人 (StellasoraBot)

《星塔旅人》官方活动日历与提醒 QQ 机器人。

自动抓取并解析《星塔旅人》官方网站公告，提供实时活动进度查询、到期提醒推送，并支持使用无头浏览器一键生成高清版本活动日历长图海报。

---

## 🌟 核心功能

- 📅 **版本活动日历长图**：一键渲染当期版本全局时间轴日历海报，包含限定卡池、大版本活动、周期玩法及精确时刻标记，自动拉取官方封面封绘并自适应主题底色。
- 🔍 **多维活动查询**：支持当前进行中活动、即将到期活动、后续开启活动查询，纯文本排版精炼清晰，无废话秒级响应。
- ⏰ **活动到期提醒**：活动结束前（默认 48 小时）主动扫描并在群聊/私聊中发送提醒，避免遗漏奖励或浪费体力。
- 📱 **官方指令面板集成**：对接腾讯 QQ 开放平台 API-v2，用户在群聊/单聊输入框键入 `/` 即可唤起官方原生交互菜单。
- 🛠 **容错与人工介入**：针对官方临时维护改口或复杂双线活动，提供完整的管理员指令（查看待确认、时间覆盖、隐藏/显示）。
- 🚀 **超轻量独立常驻**：Go 语言原生编写，零多余外部运行时，可完美无感常驻于 Android 手机（Termux）或轻量云服务器（实测与 Minecraft Paper 服务器共存零干扰）。

## 📖 指令大全

### 1. 公开指令（群成员与单聊均可直接使用）

所有指令均支持 **直接发送**（如在单聊中直接发 `/calendar`）或 **艾特机器人发送**（如 `@机器人 /calendar`），同时支持在聊天框输入 `/` 唤起官方菜单点击触发：

| 指令 | 说明 | 示例返回内容 |
| :--- | :--- | :--- |
| `/calendar` | **版本活动日历** | 发送高清版本活动日历长图海报，带全量活动封绘与时间进度轴 |
| `/events` | **当前进行中活动** | 列出当前所有正在开放的活动、限定招募、周期玩法及剩余时间 |
| `/ending` | **即将结束的活动** | 列出未来 48 小时内即将截止的活动，提醒玩家及时兑换奖励 |
| `/upcoming` | **即将开启的活动** | 列出已在公告公布、但尚未开启的新版本内容与预热卡池 |
| `/help` | **指令帮助** | 查看机器人使用说明与全部支持的命令菜单 |

---

### 2. 管理员指令（用于运营与数据订正）

仅限群主、群管理员或白名单单聊管理员使用：

| 指令 | 格式 | 说明 |
| :--- | :--- | :--- |
| `/review` | `/review` | 查看当前尚未自动识别、或待人工复核的公告条目 |
| `/override` | `/override <活动ID> <开始时间> <结束时间> [标题]` | 强制修正指定活动的时间窗口（应对官方临时维护改口） |
| `/confirm` | `/confirm <活动ID>` | 确认人工核验通过，转为正式日历条目 |
| `/hide` | `/hide <活动ID>` | 在日历与查询列表中隐藏该条目（如测试公告、已作废内容） |
| `/show` | `/show <活动ID>` | 重新公开并显示被隐藏的活动条目 |

## 🖼 日历海报效果示例

## ⚙️ 快速上手与运行配置

### 1. 环境依赖

- **Go**：1.22 及以上版本
- **无头浏览器（可选，日历图功能所需）**：
  - Windows: 安装 Google Chrome 或 Microsoft Edge
  - Linux / Termux: 安装 `chromium` 与中文字体（如 `Noto Sans CJK SC`）
  - *注：若不配置浏览器，机器人将自动降级为“极简纯文本模式”，文本查询与到期提醒照常工作。*

---

### 2. 配置文件准备

在项目根目录新建 `creds.json`（已在 `.gitignore` 中排除，请妥善保管）：

```json
{
  "appId": "你的QQ机器人AppID",
  "clientSecret": "你的QQ机器人AppSecret"
}
```

---

### 3. 一键注册腾讯官方指令菜单

运行内置的面板注册工具，将公开指令一键提交给腾讯开放平台审核生效：

```bash
go run ./cmd/panelreg -creds creds.json
```

---

### 4. 运行机器人

#### 方式 A：标准本地运行

```bash
# 纯文本模式（无需浏览器，占用仅数十MB）
go run ./cmd/xingtabot -creds creds.json -db data/xingta.db

# 启用日历出图模式（指定浏览器路径）
go run ./cmd/xingtabot -creds creds.json -db data/xingta.db -chrome "C:/Program Files/Google/Chrome/Application/chrome.exe"
```

#### 方式 B：手机 Termux 守护常驻（推荐用于闲置旧手机低功耗部署）

项目在 `deploy/phone/` 提供了开箱即用的 Termux 管理脚本：

```bash
cd ~/xingtabot

# 启动（screen 后台守护 + 自动适配 Termux 无头 Chromium 与阿里/腾讯 DNS）
./start.sh

# 查看实时运行状态与最新日志
./status.sh

# 持续跟踪日志输出
./logs.sh

# 优雅停止（安全释放并刷盘 bbolt 数据库）
./stop.sh
```

## 🏗 技术设计与架构特点

1. **分层严格解耦**：
   - 依赖严格单向流动：`cmd → feature → command/annsync → kernel → qq/store`。
   - 基础设施只暴露接口（`Doc`, `View`, `Writer`, `API`），业务功能互不依赖。
2. **零卡顿响应机制**：
   - `/calendar` 采用 **二级本地缓存** + **后台预热** 机制，秒级即问即答，杜绝网络延迟阻塞用户会话。
   - 官方 CDN 下载自带防风控冷却（5分钟失败冷却），兼顾抓取成功率与安全性。
3. **Android Termux 深度调优**：
   - 内置 Android DNS 自动降级与根证书定位机制；
   - 自动挂载 Android 系统字库（`/system/fonts/NotoSansCJK-Regular.ttc`），彻底杜绝方块字（豆腐块）；
   - 补充 `--no-sandbox` 与 `--disable-dev-shm-usage`，完美绕过移动端内核隔离限制。
